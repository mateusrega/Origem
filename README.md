# ✨ Visão Geral

**Origem** é um laboratório digital que reúne conhecimento científico, visualizações interativas e projetos experimentais.

Seu objetivo é responder uma das maiores perguntas da humanidade:

> **Como a complexidade surgiu a partir da simplicidade?**

O projeto percorre toda a história conhecida do Universo:

- ⚛ Física
- 🌌 Cosmologia
- ⭐ Formação das estrelas
- 🪐 Planetas
- 🧪 Química
- 🧬 Origem da vida
- 🦠 Evolução
- 🧠 Inteligência
- 🤖 Vida Artificial (ALife)

# 📖 Filosofia

O projeto busca mostrar que a complexidade não precisa ser projetada diretamente.

Pequenas regras locais podem produzir:

- estrelas
- planetas
- moléculas
- células
- organismos
- ecossistemas
- inteligência

Tudo emerge gradualmente.
